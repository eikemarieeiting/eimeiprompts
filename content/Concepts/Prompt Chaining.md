# Prompt Chaining

**What it is**
This technique gives a sequence of tasks, "if this then that"

**When to use it**
To break down complex tasks, questions or answers into a logical, easier to grasp format.

**Example**

```
Break down the question into smaller segments, then answer in an order that builds on the previous one.
```
