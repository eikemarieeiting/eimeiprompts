# Simple Prompt for Image Generation

**What it is**

1. ****Subject**** — The main thing to be focused, focus of the image
2. ****Background**** — Context of the image, surroundings, additional information relevant for the image
3. ****Equipment**** — The tools used, i.e. Canon EOS R5, Brushpen, Oil painting, this defines the style partly
4. ****Style**** — Type of image, lighting, mood, "in the style of Pixar", "natural"

**When to use it**
This is a great starting point for image generation, it delivers specifics and constraints and describes the visual composition.

**Example**

```
Create an image, JPG, please:

A beach scenery, the focus is a huge container ship leaving the harbor guided by smaller ships.

The background is the focus, the front is the blurry river beach line of Hamburg. A café, some people, in the back the Elbe river with the ship.

This photo is taken by an iPhone.

It's a gloomy September morning, the water is flat, the air fresh, the sky shows some clouds, it's hinting at a beautiful semi-warm day. 
```
